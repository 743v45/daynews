开源零依赖、超轻量级的 SQLite 数据库“时间机”调试工具。基于纯 PHP 8+ 和原生 JS 构建，提供 Web 界面和 CLI 守护进程，实时监控 SQLite 文件变化并自动创建快照，可在本地开发时像拖动视频进度条一样将数据库回退到任意历史状态（如 3 分钟前）。支持 WAL 模式备份、快照对比、固定与导出，以及多语言界面，采用 MIT 许可证。
