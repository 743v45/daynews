Gregory Szorc 开发了自包含、高度可移植的 Python 发行版，包含完整的 Python 标准库和静态链接的依赖项，最大限度地减少运行时依赖。该项目支持多种架构，还可与 PyOxidizer 配合使用，将 Python 嵌入到更大的二进制文件中。
